# Awtarchy v4.2.0: Dual-Compositor Support

Awtarchy now supports **standard Sway as an optional maintained Wayland compositor alongside Hyprland**. Hyprland remains the default.

## What's new

- Fresh installations offer Hyprland, Sway, or both, with selectable Ly sessions and separate compositor/Quickshell profiles.
- `awtarchy compositor` provides install, review, update, and removal options. It operates against an exact published release rather than requiring the old experimental branch.
- `awtarchy update` and `awtarchy review` include installed Sway managed files when the Sway baseline is present; personalized output layouts and modified files are preserved.
- Sway gains compatible numbered-workspace/window shortcuts, its own Quickshell bar and flyouts, secure Quickshell locking, screenshot controls with 15% confirmation sound, and Sway-native OBS screen sharing through the portal.
- Sway `Super+Ctrl+M` now launches `nwg-displays` rather than Hyprmoncfg. A guarded first-time import transfers the active Hyprland layout and compatible settings from an active matching Hyprmoncfg profile.
- Sharing between sessions keeps existing Hyprland configuration intact; removal protects untracked and shared packages.

## Known differences

Sway is intentionally simpler than Hyprland: Hyprland's blur, animations, digital-vibrance shaders, and Screen Share Guard are not provided by the standard Sway integration. Some compositor and GPU-specific behavior still requires hardware validation. A saved Hyprmoncfg profile is not automatically synchronized after the initial guarded import.

## Updating

Existing installations: `awtarchy update`.

Then open `awtarchy compositor` to review or add Sway. Previously installed Sway trial profiles retain their personal settings and legacy file paths.

Fresh installs: follow [INSTALL.md](https://github.com/dillacorn/awtarchy/blob/main/INSTALL.md). Update and compositor-management behavior is documented in [UPDATING.md](https://github.com/dillacorn/awtarchy/blob/main/UPDATING.md).

## Validation

Release publication is gated on passing Awtarchy and Sway validation for the exact merged `main` revision. Live Sway testing confirmed the monitor editor and custom audio adjustment on the developer's hardware; this does not establish compatibility on every GPU and monitor configuration.
