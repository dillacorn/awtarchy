# Awtarchy v4.3.2: Sway and Umbriel Keybinding Fixes

This patch release improves keyboard and window-management consistency across optional Sway and Umbriel sessions while preserving Hyprland as the default compositor.

## Fixes

- **Umbriel directional resizing:** A compositor-local helper inspects the focused window and neighboring Dwindle tiles through Umbriel IPC, then moves the shared divider left, right, up or down regardless of which adjacent window has focus. It also guards against missing dividers, unrelated workspaces and focus changes. Floating windows and non-Dwindle layouts retain native fractional resizing.
- **Sway and Umbriel shortcuts:** Restores and documents Hyprland-aligned window, utility, workspace, theme, launcher and monitor shortcuts, including missing Umbriel `noalt` bindings and Sway workspace-transfer aliases.
- **Quickshell launcher:** Replaces obsolete Fuzzel keybindings with Quickshell. Optional-compositor installation no longer requires Fuzzel, and imported legacy Fuzzel shortcuts are redirected to Quickshell.
- **Wallpaper and desktop controls:** Restores Sway Awtwall random-wallpaper shortcuts. Both optional compositors gain the Quickshell lockscreen-editor shortcut and monitor-brightness controls.
- **Window split control:** Sway's Alt+Shift+R no longer reloads the compositor; both optional compositors expose their native split-orientation action where supported. An explicit Sway reload remains available on Super+Alt+Shift+R.
- **Regression coverage:** Adds checks for resize directions, IPC handling, shortcut aliases and mode parity, with a detailed account of remaining compositor-specific limitations in `compositors/COMPOSITOR_PARITY.md`.

## Install and update

- New installations: [INSTALL.md](https://github.com/dillacorn/awtarchy/blob/main/INSTALL.md).
- Existing users: [UPDATING.md](https://github.com/dillacorn/awtarchy/blob/main/UPDATING.md). Use `awtarchy review` followed by `awtarchy update`. Log out and back into Sway or Umbriel for compositor binding changes to take effect.
- If testing an unreleased branch through `awtarchy git`, return to the stable release using `awtarchy update`.

## Validation

- Pull-request automated tests cover Sway and Umbriel configurations, window-resize helper behavior, Fuzzel retirement and legacy shortcut migration.
- Publication requires successful Awtarchy, Sway and Umbriel workflows on the exact `main` revision. The publisher refuses to overwrite an existing tag or publish an outdated commit.
- Live validation remains necessary for Sway input behavior and optional-compositor integration on individual hardware and personalized configurations. Native actions are not claimed to reproduce Hyprland-only features such as `swapsplit`.
