# Awtarchy v4.2.1: Sway TTY Launch

## Fix

- Awtarchy Sway can now be started by typing `sway` at a local TTY, matching Hyprland's short `hypr` command. Ly remains optional.
- The command runs Awtarchy's existing Sway session wrapper, retaining the correct environment and managed compositor configuration.
- Awtarchy installs the entry at `~/.local/bin/sway` without overwriting the package-owned `/usr/bin/sway`; arguments such as `sway -C` continue to use native Sway.
- User-created `sway` launchers are preserved. Managed Sway updates install the missing entry for existing v4.2.0 installations; compositor removal removes only a matching, unmodified Awtarchy entry.
- Bash TTY login hints list installed compositor commands, and the installation documentation includes the no-Ly startup path.

## Update

Run `awtarchy review` followed by `awtarchy update` to apply the new release. Existing Sway users receive the `sway` TTY launcher during the Sway managed-file update. Fresh installations receive it automatically.

Note: a customized `~/.bash_profile` is preserved, so its optional TTY greeting may not be updated automatically. Awtarchy does not require the greeting to launch Sway.

## Validation

Release publication requires all main-branch GitHub Actions checks, including Sway's TTY and managed-update regression tests, to pass on the exact merged commit. Real TTY graphical startup still requires live hardware verification.
