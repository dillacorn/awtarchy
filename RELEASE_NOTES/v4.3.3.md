# Awtarchy v4.3.3: Installer Reliability Fixes

This patch release corrects interrupted-install detection and package error handling so the installer does not report a usable desktop when required components were never installed.

## Fixes

- **Interrupted installation detection:** A system-wide package ownership record can no longer make an incomplete first installation look like an existing Awtarchy desktop. Legacy migration now requires user-local desktop evidence.
- **Existing-install verification:** Maintenance-only refresh now checks the actual Foot, Quickshell, and compositor packages along with the managed configuration and version state. An incomplete installation produces an explicit recovery error instead of silently skipping installation.
- **Package failure handling:** Failed `pacman` transactions, packages still missing afterward, and selected Arch package failures now stop the installer. Failed package ownership recording also returns an error.
- **Required desktop packages:** The selected compositor, Quickshell, Foot, and necessary multimedia packages are installed even if optional Arch application groups are deselected. The existing required Sway package stage remains intact.
- **Configuration completeness:** Setup now verifies that the selected compositor's managed configuration, Foot configuration, and Quickshell shell configuration exist before reporting installation success.
- **Regression tests:** Adds isolated missing-package and interrupted-install tests, covers Hyprland, Sway, and combined installations, and updates older test fixtures to model completed desktops rather than command-only installations.

## Install and update

- New installations: [INSTALL.md](https://github.com/dillacorn/awtarchy/blob/main/INSTALL.md).
- Existing users: [UPDATING.md](https://github.com/dillacorn/awtarchy/blob/main/UPDATING.md). Regular `awtarchy update` remains the path for a working installation.
- **Previously incomplete first installs:** Run the current `awtarchy-install.sh` with `--reinstall` only after reviewing the installer selections and any existing personal configuration. The installer refuses a misleading maintenance-only refresh; it does not automatically reset or overwrite your files.
- Existing working systems are not automatically reinstalled.

## Validation

- The new mock-based installer tests check failed and missing packages, normal existing-install recognition, legacy-install safeguards, and missing managed configuration.
- The Awtarchy, Sway, and related repository CI checks validate the patch. Publication requires successful workflows on the exact merged `main` commit.
- Automated tests do not prove a real fresh Arch hardware installation. The exact cause of another user's earlier barebones installation remains unverified without that machine's installation record.
