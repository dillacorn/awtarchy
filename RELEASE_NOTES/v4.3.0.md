# Awtarchy v4.3.0: Umbriel Support

Awtarchy now supports [Umbriel](https://github.com/noctalia-dev/umbriel) as an optional maintained Wayland compositor alongside default Hyprland and optional Sway. Each uses a separate Quickshell profile; existing compositor configurations are preserved.

## Changes

- **Umbriel:** Install or remove using `awtarchy compositor`. Uses the upstream `umbriel-git` package and native Ly session, with no duplicate desktop entry. From a local TTY, type `umbriel` to launch the same session; Umbriel's native IPC commands retain normal operation.
- **Permanent configuration:** Umbriel's managed files live at `~/.config/umbriel/awtarchy/`, with an isolated `awtarchy-umbriel` Quickshell shell. Existing `awtarchy-trial` configuration remains available as a fallback while the managed checksum baseline and eligible user modifications are migrated safely.
- **Desktop integration:** Workspaces, outputs, themes, bar and flyouts, screenshot/capture controls, btop/Wiremix toggles, floating-only mode, notifications, wallpaper and shortcuts are mapped to Umbriel.
- **Sway and Umbriel:** Added shared sched-ext controls, bar shortcuts and related Quickshell parity improvements. Umbriel's screenshot and login audio now use private managed resources; its window placement preview follows the selected Awtarchy theme.
- **Preservation:** No existing Hyprland or Sway installation is removed or reset by installing Umbriel. Installer and updater keep GPU drivers and custom compositor configuration under user control.

## Known differences

- Umbriel has compositor-specific window and workspace behavior; its layer-shell flyouts are bar-anchored rather than free-floating.
- `wdisplays` changes do not automatically persist into Awtarchy's native Umbriel output or workspace rules.
- GPU, audio, scheduler switching and lockscreen privacy/security behavior may require further hardware testing. The experimental Quickshell lockscreen should not be treated as security-validated.

## Install and update

- New installations: [INSTALL.md](https://github.com/dillacorn/awtarchy/blob/main/INSTALL.md)
- Existing users: [UPDATING.md](https://github.com/dillacorn/awtarchy/blob/main/UPDATING.md); use `awtarchy review` then `awtarchy update` to apply this release.
- To add Umbriel, open `awtarchy compositor` and choose **Install Umbriel**. Optional compositor installation does not reinstall the base desktop.

## Validation

- Umbriel Quickshell rendering, TOML, migration, managed-file preservation, launch paths and compositor integration have dedicated automated tests.
- Sway and general Awtarchy CI also validate the release. Publication requires successful checks on the exact `main` commit.
- Umbriel has been manually tested on the developer's desktop for core window management and Quickshell behavior; this does not establish validation on all GPUs. Remaining runtime limitations are documented above.
