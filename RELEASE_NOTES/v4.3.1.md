# Awtarchy v4.3.1: Quickshell and Umbriel Fixes

This patch release fixes keyboard selection in Quickshell and improves Umbriel's submap and Steam window behavior.

## Fixes

- **Quickshell launcher and Clipboard History:** Keyboard selection no longer jumps to a result under a stationary mouse cursor. Actual pointer movement enables hover selection; typing and arrow-key navigation restore keyboard control. Applies to Hyprland, Sway and Umbriel.
- **Umbriel submaps:** Escape now reaches the focused application or popup instead of resetting `noalt`, `mouse` or `vm` mode. Explicit Super+Alt+N/M/V mode shortcuts remain available.
- **Umbriel Steam layout:** Steam and Friends List can automatically use the intended 80/20 tiled arrangement on launch without affecting unrelated or floating windows.

## Install and update

- New installations: [INSTALL.md](https://github.com/dillacorn/awtarchy/blob/main/INSTALL.md)
- Existing users: [UPDATING.md](https://github.com/dillacorn/awtarchy/blob/main/UPDATING.md). Use `awtarchy review` followed by `awtarchy update`.

## Validation

- Launcher and clipboard pointer-selection regression tests cover stationary cursors, genuine pointer motion, and keyboard selection.
- Umbriel tests cover preserved explicit submap toggles and the Steam layout helper.
- Publication is gated on successful main-branch CI for the exact release commit, including Awtarchy, Sway and Umbriel. Live behavior on individual compositor sessions and GPU configurations still requires testing.
